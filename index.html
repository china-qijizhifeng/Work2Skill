01 / OUR CONTRIBUTIONSInfrastructure · Dataset · Method

Three contributions.
From experience to skill.

Unfamiliar software requires procedural knowledge that a task request rarely spells out. Work2Skill captures that knowledge in human demonstrations and turns it into skills an agent can use.

  1. 01
    RECORDING INFRASTRUCTURE

    WorkRecorder

    Make demonstrated actions interpretable.

    Connect each action to its visual and UI context.

    A click location alone leaves the target and its effect ambiguous. WorkRecorder links screen video, keyframes, mouse and keyboard events, and available accessibility information on a shared timeline.

    What this enables An agent can inspect a control’s meaning and the state changes around an operation.

  2. 02
    SHARED DEMONSTRATION RESOURCE

    WorkDemo-350

    Study skill induction on the same human experience.

    Provide 350 desktop demonstrations with linked evidence.

    The dataset packages 64 MyPCBench Bounded Action tasks and a selected 286-task OSWorld-Verified subset, with recordings, action traces, input logs, and evidence images.

    What this enables Methods can use the same source episodes and be compared under shared downstream execution settings.

  3. 03
    SKILL-INDUCTION METHOD

    Agentic skill induction

    Recover a procedure that can be reused.

    Interleave evidence inspection with skill writing.

    The induction agent chooses relevant files, images, and video intervals, then revisits evidence as questions arise. It generalizes instance-specific inputs while preserving workflow rules, step dependencies, and completion checks.

    What this produces A reusable SKILL.md that guides execution without access to the original recording.

The release includes recording and induction components plus task definitions; full execution runners and evaluation integration are still pending.

Dataset scope & provenance +

The released dataset card documents a post hoc OSWorld selection: 286 of 321 recorded tasks were retained after excluding 35 tasks where GPT-5.5 scored 1 without skills but less than 1 with v6 skills. This selection affects estimates of improvement; the subset is not the full official OSWorld-Verified test set.

The release is an offline demonstration resource. It does not include VM images or a complete evaluator. See the dataset card for selection, annotation, privacy, and licensing details.
