# P7 Recording UI Status

## Scope

This worktree implements the first release-candidate UI loop for region recording:

- `⌃⌥⌘R` enters region recording preparation, not direct recording.
- Recording starts only after explicit region confirmation.
- ScreenCaptureKit records the fixed selected region with WorkRecorder HUD windows excluded from the video stream.
- Active Capture session, start/final keyframes, user marks, controls, segments, completion, and discard are wired through typed backend APIs.
- Ordinary current-window and region screenshot flows remain unchanged.
