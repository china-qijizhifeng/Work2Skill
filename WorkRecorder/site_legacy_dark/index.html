WorkRecorder
主动上下文事件层

用一次截图触发，把工作现场变成 Agent 可引用的上下文。

WorkRecorder 是面向工作 Agent 的主动式上下文事件层。用户只记录关键屏幕证据， 系统补齐来源上下文，生成可引用、可审计、可控权限的 Context Bundle。

看 ACME 场景 理解处理链路 阅读技术架构
上下文散落网页、聊天、CRM、邮件各说一半
复制成本高用户不想把四处信息搬进 prompt
系统截图工具不够普通截图没有来源、索引和权限边界
用户主动记录信噪比高，Agent 只拿关键证据
WorkRecorder 把“截图动作”升级成一条 Context Event 选区 + note + 来源补齐 + evidence refs，一次触发后可搜索、可引用、可审计。

为什么有价值

WorkRecorder 解决的是 Agent 的证据缺口。

少解释

用户不用重讲现场

一句 intent 加两次主动记录，就能让 Agent 找到报价、聊天和 CRM 证据。

补来源

截图截不全也能补齐

浏览器补全文，聊天补 thread，CRM/邮件补字段和来源链接。

可引用

输出能回到证据

每条结论都带 event id 和 evidence ref，方便复核、审计和团队协作。
